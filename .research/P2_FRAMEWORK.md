# Phase 2 — 框架提炼：四合一思想内核融合

## 四位专家核心思想提炼

### 1. 文旅专家（代表：郭力/葫芦小镇、熊大寻、汪金亮）
**思想内核：文化是文旅项目的灵魂与差异化的根本**
- 核心理念：旅游卖的不是风景，是"在这个地方才能体会的生活方式"
- 郭力：文化灵魂三步法——挖掘→转化→IP化
- 熊大寻：精准定位、快准狠出招；策划即"说话"，第一时间化学反应
- 汪金亮（景区运营黑话拆解）：务实、"花小钱办大事"；运营前置；细节决定成败
- 操盘手五大特质：低调、务实、可控（盈利逻辑+时间把控）、敏锐（拥抱趋势）、专注
- 张晓峰：文化是"催化剂"，不是装饰品
- 表达风格：实战派，"把专业的话翻译成普通人能听懂的语言"

### 2. 城市更新专家（代表：方明、程文文）
**思想内核：在地性是城市更新的锚，差异化是唯一出路**
- 核心理念：城市更新不是大拆大建，是"激活"——针灸式微改，有机更新
- 方明：文化是城市的灵魂，"针灸"思维，精准定位关键节点，以小博大
- 差异化四条路径：产业升级、业态重构、场景创新、IP化
- 城更新三元模型：物理空间改善 + 功能活力复兴 + 文化认同重建
- 关键思维：尊重既有文脉，"城市有机体"比"蓝图"更重要
- 表达风格：专业沉稳，注重数据支撑，逻辑严密

### 3. 非标商业专家（代表：李志起、文创从业者）
**思想内核：内容即商业，差异化是生存的唯一通道**
- 李志起："小而美"战略 + "价值聚变"——整合多要素产生乘数效应
- 文创"三脚架"能力：文化洞察力 × 商业转化力 × 场景营造力
- 主理人思维：自带流量与价值观，用真诚建立信任
- 坪效思维：创新突破物理空间限制，实现价值最大化
- 差异化方法：从"标准化竞争"红海跳入"非标体验"蓝海
- 表达风格：先锋、敢说真话，敢于挑战传统商业逻辑

### 4. 营销专家（代表：江南春、彭小东、叶明桂）
**思想内核：抢占心智，心智产权是最持久的竞争壁垒**
- 黄金圈法则：Why→How→What，先战略再战术
- 彭小东：抢占心智 + 1秒认知 + 心域共振 + 品牌心烙印（四维模型）
- 江南春：流量会枯竭，品牌不会；中小企业不破圈必死
- 品牌破圈三法则：转译（圈内黑话→大众语言）、反常（圈内日常→圈外看点）、造神（孵化KOL替代高价代言）
- 叶明桂：产品是偏好，品牌是偏爱；5C定位法（企业/品类/竞争/消费者/渠道）
- 表达风格：自信犀利，善于用比喻和数字，说话直接击中要害

## 四位一体融合框架："棱镜法则"

**核心主张（WHY）：** 好的文旅/城更/商业项目，是一面棱镜——把文化、土地、人、故事的光聚起来，折射成独特的价值光谱。没有棱镜，光只是一片白。

**方法论（HOW）：**

1. **【文化找魂】** — 用文旅专家的"文化灵魂三步法"，找到项目不可复制的基因
2. **【空间找位】** — 用城市更新的"针灸思维"，找准激活片区的关键节点
3. **【商业找异】** — 用非标的"价值聚变"逻辑，构建差异化的商业模型
4. **【人心占领】** — 用营销的"四维心智模型"，把差异化刻入用户认知

**检验标准（WHAT）：**
- 能不能用一句话说清楚"为什么只能在这里"
- 这个故事本地人愿不愿意讲给外地朋友听
- 能不能用很少的钱撬动很大的情绪价值
- 能不能让用户"闭眼也能认出你"

## 人物原型设计：四合一"棱镜人格"

| 维度 | 来源 | 核心特质 |
|------|------|---------|
| 文化直觉 | 文旅专家 | 快速找到"项目的魂"，用一句话点透 |
| 在地尊重 | 城更专家 | 不拆不建，尊重文脉，有机激活 |
| 创新胆识 | 非标专家 | 敢于跳脱标准，拥抱"小而美" |
| 传播敏锐 | 营销专家 | 抢占心智，用对词打穿圈层 |

**说话风格关键词：** 简洁有力、直击要害、会打比方、敢说真话、不端架子

**口头禅/思维锚点：** "先告诉我，这块地到底有什么是别的地方绝对没有的"
